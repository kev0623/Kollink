# Kollink 登入與註冊 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓品牌和創作者可以用 Google 或 Email 驗證碼註冊、登入、填寫基本資料，並進入各自的頁面骨架；同時把專案改名為 Kollink。

**Architecture:** Supabase Auth（`@supabase/ssr`）處理 session；`src/proxy.ts` 只更新 cookie 與擋未登入；各區 layout 在 `<Suspense>` 內呼叫 `getCurrentUser()` 做導向；建立帳號只能經由 SECURITY DEFINER 函式；真正的權限由 RLS 負責。

**Tech Stack:** Next.js 16.4.6（App Router、`cacheComponents`、`proxy.ts`）、React 19.3、TypeScript、Tailwind v4、Supabase CLI 3.2（Postgres、Auth、Storage、Mailpit）、pgTAP、Vitest。

**Spec:** `docs/superpowers/specs/2026-11-23-auth-design.md`

## Global Constraints

- Next.js 16 與訓練資料不同：寫程式前先讀 `node_modules/next/dist/docs/` 對應文件。`middleware.ts` 已改名為 `proxy.ts`（匯出 `proxy` 函式）。
- `cacheComponents` 已開啟：讀 `cookies()`、`headers()`、`searchParams` 的元件必須在 `<Suspense>` 內；不要在 layout 最外層 await session（見 `node_modules/next/dist/docs/01-app/02-guides/authentication-with-cache-components.md`）。不可使用 `export const runtime`。
- 金鑰：`NEXT_PUBLIC_SUPABASE_URL`、`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`（瀏覽器可見）、`SUPABASE_SECRET_KEY`（只能出現在 import `server-only` 的檔案，絕不加 `NEXT_PUBLIC_` 前綴）。
- 登入、註冊、填資料、編輯資料一律用**使用者自己的** client（`src/lib/supabase/server.ts` 或 `client.ts`），不可使用 `createAdminClient()`。
- SQL 函式一律 `set search_path = ''`，物件名稱寫完整 schema。
- 介面文字為繁體中文；產品名稱只從 `src/lib/site.ts` 的 `SITE_NAME` 取得。
- 顏色只用 `globals.css` 的 token class（`bg-primary`、`bg-primary-soft`、`bg-bg`、`bg-surface`、`text-ink`、`text-muted`、`border-line`、`text-success`、`bg-success-soft`、`rounded-card`、`rounded-btn`）。
- 不新增 npm 套件，除了 `@supabase/ssr`。
- 每個 task 結束時：`npm run lint && npm run typecheck && npm test` 全過；有動到 SQL 的 task 另跑 `npx supabase test db` 全過。
- Commit 訊息用中文寫「計畫 2 Task N：重點」，結尾加你所在環境指定的 Co-Authored-By 歸屬行（寫實際執行的模型）。
- 前置：Docker Desktop 已啟動，`npx supabase start` 已執行。

- [ ] **Step 6: `src/lib/supabase/server.ts`**

```ts
import "server-only";
import { createServerClient } from "@supabase/ssr";
import { cookies } from "next/headers";
import { requireEnv } from "@/lib/env";
import type { Database } from "./database.types";

/** 以「目前登入的使用者」身分存取 Supabase，RLS 與狀態函式會依使用者身分判斷。 */
export async function createClient() {
  const cookieStore = await cookies();
  return createServerClient<Database>(
    requireEnv("NEXT_PUBLIC_SUPABASE_URL"),
    requireEnv("NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY"),
    {
      cookies: {
        getAll: () => cookieStore.getAll(),
        setAll: (list) => {
          try {
            list.forEach(({ name, value, options }) => cookieStore.set(name, value, options));
          } catch {
            // Server Component 不能寫 cookie；session 由 proxy 負責更新。
          }
        },
      },
    },
  );
}
```

- [ ] **Step 8: `src/lib/supabase/proxy.ts`**

```ts
import { createServerClient } from "@supabase/ssr";
import { NextResponse, type NextRequest } from "next/server";
import type { User } from "@supabase/supabase-js";
import { requireEnv } from "@/lib/env";
import type { Database } from "./database.types";

/** 更新 session cookie，並回傳目前使用者（未登入為 null）。 */
export async function updateSession(request: NextRequest): Promise<{ response: NextResponse; user: User | null }> {
  let response = NextResponse.next({ request });
  const supabase = createServerClient<Database>(
    requireEnv("NEXT_PUBLIC_SUPABASE_URL"),
    requireEnv("NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY"),
    {
      cookies: {
        getAll: () => request.cookies.getAll(),
        setAll: (list) => {
          list.forEach(({ name, value }) => request.cookies.set(name, value));
          response = NextResponse.next({ request });
          list.forEach(({ name, value, options }) => response.cookies.set(name, value, options));
        },
      },
    },
  );
  const {
    data: { user },
  } = await supabase.auth.getUser();
  return { response, user };
}
```

  p_handle text,
  p_ig_username text,
  p_follower_count integer,
  p_region text,
  p_categories text[]

-- 品牌 Logo（計畫 2）
insert into storage.buckets (id, name, public, file_size_limit, allowed_mime_types)
values ('brand-logos', 'brand-logos', true, 2097152, array['image/png', 'image/jpeg', 'image/webp'])
on conflict (id) do update set
  public = excluded.public,
  file_size_limit = excluded.file_size_limit,
  allowed_mime_types = excluded.allowed_mime_types;

-- 檔名規則與 brand_profiles.logo_path 一致：<uid>/<檔名>，不可巢狀資料夾、不可以 . 或 - 開頭、不可含 ..

create policy brand_logos_select_own on storage.objects
  for select to authenticated
  using (bucket_id = 'brand-logos' and (storage.foldername(name))[1] = auth.uid()::text);
create policy brand_logos_insert_own on storage.objects
  for insert to authenticated
  with check (
    bucket_id = 'brand-logos'
    and (storage.foldername(name))[1] = auth.uid()::text
    and public.my_role() is distinct from 'creator'
    and name ~ ('^' || auth.uid()::text || '/[A-Za-z0-9][A-Za-z0-9._-]{0,99}$')
    and name !~ '\.\.'
  );
create policy brand_logos_update_own on storage.objects
  for update to authenticated
  using (bucket_id = 'brand-logos' and (storage.foldername(name))[1] = auth.uid()::text)
  with check (
    bucket_id = 'brand-logos'
    and (storage.foldername(name))[1] = auth.uid()::text
    and public.my_role() is distinct from 'creator'
    and name ~ ('^' || auth.uid()::text || '/[A-Za-z0-9][A-Za-z0-9._-]{0,99}$')
    and name !~ '\.\.'

create policy brand_logos_delete_own on storage.objects

/** 只接受站內路徑，避免登入後被導到外部網站（open redirect）。 */
export function safeNextPath(input: string | null | undefined): string | null {
  if (!input || input.length > 512) return null;
  if (!input.startsWith("/")) return null;
  if (input[1] === "/" || input[1] === "\\") return null;
  if (/[\u0000-\u001f\u007f]/.test(input)) return null;
  return input;
}

export type Role = "brand" | "creator";

export function isRole(v: unknown): v is Role {
  return v === "brand" || v === "creator";
}

export function homeFor(role: Role): "/brand" | "/creator" {
  return role === "brand" ? "/brand" : "/creator";
}

/** 登入後要去哪裡。規則見 docs/superpowers/specs/2026-11-23-auth-design.md 第 1 節。 */
export function resolvePostLoginPath(a: { role: Role | null; requestedRole: string | null; next: string | null }): string {
  if (!a.role) return isRole(a.requestedRole) ? `/onboarding/${a.requestedRole}` : "/onboarding";
  const home = homeFor(a.role);
  const next = safeNextPath(a.next);
  if (next && (next === home || next.startsWith(`${home}/`) || next.startsWith(`${home}?`))) return next;
  return home;
}

// 規則與 supabase/migrations/20261123000100_accounts.sql 一致；資料庫是最後防線。

export const HANDLE_RE = /^[a-z0-9_.]{3,30}$/;
export const IG_RE = /^[A-Za-z0-9_.]{1,30}$/;

// 與資料庫 clean_text / has_bidi 必須是完全相同的集合（見 20261123000100_accounts.sql）。
// 1) 任何位置一律移除：U+200B、U+2060、U+FEFF（U+200C、U+200D 只在前後去除，以免拆散 emoji）
// 2) 去掉前後的空白與看不見的字元：ASCII 空白、U+0085、U+00A0、U+00AD、U+034F、U+061C、
//    U+115F、U+1160、U+1680、U+180E、U+2000–U+200F、U+2028、U+2029、U+202F、U+205F、
//    U+2060–U+2064、U+2800、U+3000、U+3164、U+FE0F、U+FEFF、U+FFA0
// 3) 雙向控制字元 U+202A–U+202E、U+2066–U+2069 出現在任何位置都視為無效
const INNER_ZERO_WIDTH = /[\u200b\u2060\ufeff]/g;
const EDGE_CHARS =
  "\\s\\u0085\\u00a0\\u00ad\\u034f\\u061c\\u115f\\u1160\\u1680\\u180e\\u2000-\\u200f" +
  "\\u2028\\u2029\\u202f\\u205f\\u2060-\\u2064\\u2800\\u3000\\u3164\\ufe0f\\ufeff\\uffa0";
const EDGE_WS = new RegExp(`^[${EDGE_CHARS}]+|[${EDGE_CHARS}]+$`, "g");
const BIDI = /[\u202a-\u202e\u2066-\u2069]/;
const BAD_CHAR_MESSAGE = "含有不允許的特殊字元";

export function cleanText(v: string): string {
  return v.replace(INNER_ZERO_WIDTH, "").replace(EDGE_WS, "");
}

export function hasBidi(v: string): boolean {
  return BIDI.test(v);
}

/** 字數（與 Postgres char_length 一致，以 code point 計算）。 */
function len(v: string): number {
  return [...v].length;
}

export function normalizeIgUsername(v: string): string {
  return cleanText(v).replace(/^@/, "");
}

export function suggestHandle(ig: string): string {
  return normalizeIgUsername(ig).toLowerCase().replace(/[^a-z0-9_.]/g, "").slice(0, 30);
}

export type BrandInput = { brandName: string; industry: string; logoPath: string | null };

export function validateBrandInput(i: BrandInput): Record<string, string> | null {
  const e: Record<string, string> = {};
  const name = cleanText(i.brandName);
  if (hasBidi(name)) e.brandName = BAD_CHAR_MESSAGE;
  else if (len(name) < 1 || len(name) > 60) e.brandName = "請填寫品牌名稱（60 字以內）";
  const industry = cleanText(i.industry);
  if (hasBidi(industry)) e.industry = BAD_CHAR_MESSAGE;
  else if (len(industry) < 1 || len(industry) > 30) e.industry = "請選擇產業";
  return Object.keys(e).length ? e : null;
}

export type CreatorInput = {
  displayName: string;
  handle: string;
  igUsername: string;
  followerCount: string;
  region: string;
  categories: string[];
};

export function validateCreatorInput(i: CreatorInput): Record<string, string> | null {
  const e: Record<string, string> = {};
  const name = cleanText(i.displayName);
  if (hasBidi(name)) e.displayName = BAD_CHAR_MESSAGE;
  else if (len(name) < 1 || len(name) > 40) e.displayName = "請填寫顯示名稱（40 字以內）";
  if (!HANDLE_RE.test(cleanText(i.handle))) e.handle = "網址只能用小寫英文、數字、底線和點，3–30 字";
  if (!IG_RE.test(normalizeIgUsername(i.igUsername))) e.igUsername = "請填寫正確的 IG 帳號";
  if (!/^\d{1,9}$/.test(cleanText(i.followerCount))) e.followerCount = "請填寫粉絲數（整數）";
  const region = cleanText(i.region);
  if (hasBidi(region)) e.region = BAD_CHAR_MESSAGE;
  else if (len(region) < 1 || len(region) > 30) e.region = "請選擇地區";
  const cats = i.categories.map(cleanText);
  if (cats.some(hasBidi)) {
    e.categories = BAD_CHAR_MESSAGE;
  } else if (
    cats.length < 1 || cats.length > 5 ||
    cats.some((c) => len(c) < 1 || len(c) > 20) ||
    new Set(cats).size !== cats.length
  ) {
    e.categories = "請選 1–5 個內容領域";
  }
  return Object.keys(e).length ? e : null;
}

import { NextResponse, type NextRequest } from "next/server";
import { updateSession } from "@/lib/supabase/proxy";
import { requiresAuth } from "@/lib/auth/routes";

// 只做樂觀檢查：更新 session cookie、沒登入就導去 /login。身分與資料完整度由各區 layout 檢查。
export async function proxy(request: NextRequest) {
  const { response, user } = await updateSession(request);
  if (!user && requiresAuth(request.nextUrl.pathname)) {
    const login = request.nextUrl.clone();
    login.pathname = "/login";
    login.search = "";
    login.searchParams.set("next", request.nextUrl.pathname + request.nextUrl.search);
    const redirect = NextResponse.redirect(login);
    response.cookies.getAll().forEach((c) => redirect.cookies.set(c));
    return redirect;
  }
  return response;
}

  const [step, setStep] = useState<"email" | "code">("email");
  const [email, setEmail] = useState("");
  const [code, setCode] = useState("");
  const [error, setError] = useState<string | null>(null);
  const [pending, setPending] = useState(false);
  const [cooldown, setCooldown] = useState(0);

  useEffect(() => {
    if (cooldown <= 0) return;
    const t = setTimeout(() => setCooldown((c) => c - 1), 1000);
    return () => clearTimeout(t);
  }, [cooldown]);

  const query = new URLSearchParams();
  if (role) query.set("role", role);
  if (next) query.set("next", next);
  const qs = query.toString() ? `?${query.toString()}` : "";

  async function sendCode() {
    setError(null);
    setPending(true);
    const { error: e } = await supabase.auth.signInWithOtp({ email: email.trim(), options: { shouldCreateUser: true } });
    setPending(false);
    if (e) {
      setError(e.status === 429 ? "寄送太頻繁，請稍後再試" : "無法寄出驗證碼，請確認 Email 是否正確");
      return;
    }
    setStep("code");
    setCooldown(RESEND_SECONDS);
  }

  async function verify() {
    setError(null);
    setPending(true);
    const { error: e } = await supabase.auth.verifyOtp({ email: email.trim(), token: code.trim(), type: "email" });
    if (e) {
      setPending(false);
      setError("驗證碼錯誤或已過期，請重新取得");
      return;
    }
    window.location.assign(`/auth/continue${qs}`);
  }

  async function google() {
    setError(null);
    const { error: e } = await supabase.auth.signInWithOAuth({
      provider: "google",
      options: { redirectTo: `${window.location.origin}/auth/callback${qs}` },
    });
    if (e) setError("無法使用 Google 登入，請改用 Email");
  }

  return (
    <div className="rounded-card border border-line bg-surface p-6 shadow-sm">
      <button
        type="button"
        onClick={google}
        disabled={!googleEnabled}
        className="w-full rounded-btn border border-line px-4 py-2 font-bold disabled:cursor-not-allowed disabled:text-muted"
      >
        {googleEnabled ? "用 Google 繼續" : "Google 登入（尚未設定）"}
      </button>

      <div className="my-4 text-center text-sm text-muted">或用 Email 收驗證碼</div>

      {step === "email" ? (
        <form onSubmit={(e) => { e.preventDefault(); void sendCode(); }} className="space-y-3">
          <input
            type="email" required autoComplete="email" value={email}
            onChange={(e) => setEmail(e.target.value)} placeholder="you@example.com"
            className="w-full rounded-btn border border-line px-3 py-2"
          />
          <button type="submit" disabled={pending} className="w-full rounded-btn bg-primary px-4 py-2 font-bold text-white disabled:opacity-60">
            寄驗證碼
          </button>
        </form>
      ) : (
        <form onSubmit={(e) => { e.preventDefault(); void verify(); }} className="space-y-3">
          <p className="text-sm text-muted">驗證碼已寄到 {email}</p>
          <input
            inputMode="numeric" autoComplete="one-time-code" pattern="\d{6}" maxLength={6} required
            value={code} onChange={(e) => setCode(e.target.value)} placeholder="6 碼驗證碼"
            className="w-full rounded-btn border border-line px-3 py-2 tracking-widest"
          />
          <button type="submit" disabled={pending} className="w-full rounded-btn bg-primary px-4 py-2 font-bold text-white disabled:opacity-60">
            登入
          </button>
          <button
            type="button" disabled={cooldown > 0 || pending} onClick={() => void sendCode()}
            className="w-full text-sm text-muted disabled:opacity-60"
          >
            {cooldown > 0 ? `${cooldown} 秒後可以重寄` : "重寄驗證碼"}
          </button>
        </form>
      )}

      {error && <p role="alert" className="mt-3 text-sm text-primary">{error}</p>}
    </div>
  );
}

/** 資料庫只存 Logo 的 Storage 路徑（<user_id>/<檔名>）；顯示與預覽時才組成公開網址。 */
export function brandLogoUrl(path: string | null): string | null {
  if (!path) return null;
  const base = process.env.NEXT_PUBLIC_SUPABASE_URL;
  if (!base) return null;
  const encoded = path.split("/").map(encodeURIComponent).join("/");
  return `${base.replace(/\/$/, "")}/storage/v1/object/public/brand-logos/${encoded}`;
}

"use client";
import { useMemo, useState } from "react";
import { createClient } from "@/lib/supabase/client";
import { brandLogoUrl } from "@/lib/brand-logo";

const MAX_BYTES = 2 * 1024 * 1024;
const TYPES: Record<string, string> = { "image/png": "png", "image/jpeg": "jpg", "image/webp": "webp" };

export function LogoField({ userId, initialPath, error }: { userId: string; initialPath: string | null; error?: string }) {
  const supabase = useMemo(() => createClient(), []);
  const [logoPath, setLogoPath] = useState<string | null>(initialPath);
  const url = brandLogoUrl(logoPath);
  const [msg, setMsg] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);

  async function onFile(file: File | undefined) {
    if (!file) return;
    setMsg(null);
    const ext = TYPES[file.type];
    if (!ext) return setMsg("只接受 PNG、JPG、WebP");
    if (file.size > MAX_BYTES) return setMsg("檔案不能超過 2MB");
    setBusy(true);
    const path = `${userId}/${crypto.randomUUID()}.${ext}`;
    const { error: e } = await supabase.storage.from("brand-logos").upload(path, file, { contentType: file.type });
    setBusy(false);
    if (e) return setMsg("上傳失敗，請再試一次");
    setLogoPath(path);
  }

  return (
    <div>
      <span className="text-sm font-bold">Logo（選填）</span>
      <div className="mt-1 flex items-center gap-3">
        {url ? (
          // eslint-disable-next-line @next/next/no-img-element
          <img src={url} alt="Logo 預覽" className="h-12 w-12 rounded-btn border border-line object-cover" />
        ) : (
          <div className="h-12 w-12 rounded-btn border border-dashed border-line" />
        )}
        <input type="file" accept="image/png,image/jpeg,image/webp" disabled={busy} onChange={(e) => void onFile(e.target.files?.[0])} />
        {url && <button type="button" className="text-sm text-muted" onClick={() => setLogoPath(null)}>移除</button>}
      </div>
      <input type="hidden" name="logoPath" value={logoPath ?? ""} />
      {(msg || error) && <span role="alert" className="mt-1 block text-xs text-primary">{msg ?? error}</span>}
    </div>
  );
}

"use server";

import { revalidatePath } from "next/cache";
import { createClient } from "@/lib/supabase/server";
import { getCurrentUser } from "@/lib/auth/current-user";
import { mapAccountError, type FormState } from "@/lib/auth/account-errors";
import { validateBrandInput } from "@/lib/validation/onboarding";
import { parseBrandForm } from "@/lib/validation/form-data";

export async function updateBrandAction(_prev: FormState, fd: FormData): Promise<FormState> {
  const me = await getCurrentUser();
  if (!me || me.profile?.role !== "brand") return { formError: "請重新登入" };
  const input = parseBrandForm(fd);
  const fieldErrors = validateBrandInput(input);
  if (fieldErrors) return { fieldErrors };

  const supabase = await createClient();
  // 修改只能走 definer 函式（同一個 transaction 同步 profiles.display_name）；資料表沒有直接 UPDATE 權限
  // p_logo_path 是必填參數，null 代表移除 Logo（產生的型別寫成 string，所以要轉型）
  const { error } = await supabase.rpc("update_brand_account", {
    p_brand_name: input.brandName,
    p_industry: input.industry,
    p_logo_path: input.logoPath as string,
  });
  if (error) {
    const mapped = mapAccountError(error);
    return mapped.kind === "state" ? mapped.state : { formError: "發生錯誤，請稍後再試" };
  }
  revalidatePath("/brand", "layout");
  return { ok: true };
}

"use server";

import { revalidatePath } from "next/cache";
import { createClient } from "@/lib/supabase/server";
import { getCurrentUser } from "@/lib/auth/current-user";
import { mapAccountError, type FormState } from "@/lib/auth/account-errors";
import { validateCreatorInput } from "@/lib/validation/onboarding";
import { parseCreatorForm } from "@/lib/validation/form-data";

export async function updateCreatorAction(_prev: FormState, fd: FormData): Promise<FormState> {
  const me = await getCurrentUser();
  if (!me?.creator) return { formError: "請重新登入" };
  const input = parseCreatorForm(fd);
  // handle 鎖定後表單不送 handle（readOnly），沿用原本的值；鎖定以資料庫的 handle_locked_at 為準
  if (me.creator.handleLocked) input.handle = me.creator.handle;
  const fieldErrors = validateCreatorInput(input);
  if (fieldErrors) return { fieldErrors };

  const supabase = await createClient();
  // 修改只能走 definer 函式：handle 審核通過後由資料庫鎖定，display_name 同一個 transaction 同步
  const { data: newCode, error } = await supabase.rpc("update_creator_account", {
    p_display_name: input.displayName,
    p_handle: input.handle,
    p_ig_username: input.igUsername,
    p_follower_count: Number(input.followerCount),
    p_region: input.region,
    p_categories: input.categories,
  });
  if (error) {
    const mapped = mapAccountError(error);
    return mapped.kind === "state" ? mapped.state : { formError: "發生錯誤，請稍後再試" };
  }
  revalidatePath("/creator", "layout");
  // 回傳驗證碼代表更換了 IG 帳號，狀態已退回審核中（頁面頂端的 StatusBanner 會顯示新驗證碼）
  if (!newCode) return { ok: true };
  return {
    ok: true,
    notice: me.creator.status === "suspended"
      ? "已更換 IG 帳號。帳號目前暫停中，請聯絡客服"
      : "你更換了 IG 帳號，需要重新審核；新的驗證碼已顯示在頁面上方",
  };
}
